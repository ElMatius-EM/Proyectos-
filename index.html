01 · RAG
AdaGIDE AI Companion

Asistente de código para ADA 95 con la documentación exacta de la cátedra. Los LLMs generales no conocen el lenguaje — la solución es darles el contexto específico antes de responder.

⬡ RAG + Embeddings
Pipeline
1
Ingestión de documentos
PDFs de la cátedra → fragmentados → convertidos en vectores → almacenados en ChromaDB.
↓
2
Búsqueda semántica
La pregunta del usuario se convierte en embedding y se buscan los fragmentos más similares en ChromaDB.
↓
3
Contexto aumentado
Fragmentos recuperados + pregunta se combinan en el prompt antes de llamar a la API.
↓
4
Generación especializada
Claude genera código ADA 95 con las reglas específicas de la cátedra, no ADA genérico.
Aprendizaje: las prohibiciones explícitas en el system prompt son más efectivas que el RAG para reglas críticas. Más documentos no siempre mejora el resultado.

02 · Context Stuffing + NLP
Dashboard PAE

Análisis de pozos petroleros de la Cuenca del Golfo San Jorge con consultas en lenguaje natural. El usuario carga sus CSV y le pregunta a la IA directamente en español.

⬡ Context Stuffing + LLM
Pipeline
1
Carga de CSV
El usuario sube historico_pozos.csv y catalogo_pozos.csv. Papa Parse los procesa en el frontend.
↓
2
Construcción de contexto
Flask arma un resumen de los datos y lo inyecta directo en el prompt junto con la pregunta.
↓
3
System prompt especializado
El modelo recibe el rol de "analista experto en la Cuenca del Golfo San Jorge".
↓
4
Respuesta + gráficos
DeepSeek devuelve markdown con tablas. Chart.js actualiza los 4 gráficos automáticamente.
Diferencia con RAG: no hay base vectorial. Los datos van directo al prompt. Funciona porque los CSV son pequeños — con millones de filas habría que usar RAG o SQL.

03 · Structured Output + Multi-provider
Etyma

Etimología rusa para hispanohablantes. El modelo devuelve un análisis lingüístico completo en JSON estructurado, parseable directo en la interfaz. Soporta tres modelos distintos.

⬡ Structured Output
Pipeline
1
Prompt con schema fijo
El system prompt define los 8 campos del JSON que el modelo debe devolver, con estructura obligatoria.
↓
2
Selección de provider
El usuario elige entre Gemini Flash (~$0.003), DeepSeek V3 (~$0.001) o Claude Sonnet (~$0.02).
↓
3
JSON puro como respuesta
El modelo devuelve solo JSON, sin markdown. Si hay error de parsing hay fallback con try/catch.
↓
4
Caché con IndexedDB
Las palabras ya analizadas se guardan en el navegador. Sin costo repetido ni espera.
Aprendizaje: el structured output falla si el prompt no cubre todos los edge cases. Un campo ambiguo rompe el JSON. La cobertura del schema importa tanto como el modelo.
